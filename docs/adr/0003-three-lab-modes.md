# A lab asks in one of three ways

A lab is guided, a challenge, or an issue, and a scenario may mix them. A guided lab teaches the mechanism: it names the resources and settings, walks the learner through writing them, and links the vendor's pages. A challenge states the required end state and withholds the way there, including vendor links and Terraform names. An issue opens on a wrong system and a support ticket. The ticket reports the symptoms of one fault and the corrected system, and it does not name the cause. There is no vendor link and no written diagnosis. The fault is either Terraform that cannot be applied, or drift the workspace does not already repair. Drift is prepared by applying that Terraform and then changing the live cloud outside it, so state matches the workspace and applying the same files again leaves the ticket unsolved. A template that is already correct, where apply alone would repair the live cloud, is a guided lab. A wrong value sitting in the starter, a submitted root cause, and "just apply" were the alternatives. The first is easy to spot, the second is not something a check can see, and the third is not a diagnosis.
