The VPC, private subnets, ECS cluster, Cloud Map namespace and `products` service, IAM roles, and `products` NLB/target group are already defined in `main.tf`.

1. Declare an `aws_ecs_task_definition` named `products` with `family = "retaildemostore-products"`, `network_mode = "awsvpc"`, `requires_compatibilities = ["FARGATE"]`, `cpu = "256"`, `memory = "512"`, `execution_role_arn = aws_iam_role.ecs_execution.arn`, `task_role_arn = aws_iam_role.products_task.arn`, and `container_definitions` defining one container named `"products"` on port `80` (`image = "public.ecr.aws/docker/library/nginx:alpine"`).
2. Declare an `aws_ecs_service` named `products` with `name = "products"`, `cluster = aws_ecs_cluster.retail.id`, `task_definition = aws_ecs_task_definition.products.arn`, `desired_count = 1`, `launch_type = "FARGATE"`, `network_configuration` using `[aws_subnet.private_1.id, aws_subnet.private_2.id]` and `[aws_security_group.products_svc.id]`, `load_balancer` targeting `aws_lb_target_group.products.arn` on container `"products"` port `80`, and `service_registries` pointing to `aws_service_discovery_service.products.arn`.
3. Run `terraform apply` in the Terminal, then press Check.
